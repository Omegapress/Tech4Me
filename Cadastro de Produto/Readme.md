\# 📦 Cadastro de Produtos - Delphi VCL



Projeto simples em \*\*Delphi VCL\*\* para cadastro de produtos com operações básicas de CRUD.



\---



\## 🖥️ Telas



\### Tela Principal

\- Lista de produtos (DBGrid)

\- Botões:

&#x20; - Adicionar

&#x20; - Editar

&#x20; - Remover

&#x20; - Buscar por nome



\### Tela de Cadastro

\- Nome do produto

\- Preço

\- Quantidade

\- Botões:

&#x20; - Salvar

&#x20; - Cancelar

&#x20; - Limpar



\---



\## ⚙️ Funcionalidades



\- Cadastrar produtos

\- Editar produtos selecionados

\- Excluir produtos com confirmação

\- Listar produtos em tempo real

\- Buscar produtos por nome (parcial)



\---



\## 🔐 Validações



\- Todos os campos são obrigatórios

\- Preço deve ser numérico e maior que zero

\- Quantidade deve ser número inteiro positivo

\- Mensagens de erro são exibidas quando necessário



\---



\## 💾 Armazenamento



Os dados são armazenados em memória utilizando `TClientDataSet`, sem banco de dados externo.



\---



\## 🧠 Tecnologias



\- Delphi VCL

\- TClientDataSet

\- TDBGrid

\- Componentes padrão VCL



\---



\## 📌 Objetivo



Projeto desenvolvido para prática de:



\- CRUD

\- Validações

\- Comunicação entre formulários

\- Uso de dataset em memória
