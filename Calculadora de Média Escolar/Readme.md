# 📚 Calculadora de Média Escolar

Projeto simples desenvolvido no curso **Tech4me** utilizando **Delphi (VCL)**.

## 🎯 Objetivo
Criar uma aplicação que recebe três notas, calcula a média e informa a situação do aluno.

## ⚙️ Como funciona
- O usuário digita três notas
- Clica em **Calcular Média**
- O sistema mostra a média e o resultado

## 🧮 Regras
- **Aprovado** → média ≥ 7  
- **Recuperação** → média entre 5 e 6.9  
- **Reprovado** → média < 5  

## ⚠️ Validação
- Aceita apenas números
- Notas devem estar entre 0 e 10

## 🛠️ Tecnologias
- Delphi (VCL)
- Object Pascal
