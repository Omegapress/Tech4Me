# Cadastro de Usuários - Delphi

Projeto simples desenvolvido em Delphi para cadastro de usuários com validação de campos, carregamento de imagem e simulação de salvamento utilizando Timer.

## Funcionalidades

- Cadastro de informações do usuário
- Validação de campos obrigatórios
- Upload de imagem com OpenDialog
- Exibição da imagem no componente TImage
- Botão de salvar com efeito de "Salvando..."
- Simulação de processamento usando TTimer

## Componentes Utilizados

- TEdit
- TComboBox
- TButton
- TImage
- TOpenDialog
- TTimer
- TListBox
